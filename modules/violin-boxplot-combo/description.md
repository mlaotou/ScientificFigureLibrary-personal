# 详细描述

本模块展示了一个经典的组合图形式：半透明提琴图（展示数据分布密度）+ 黑色轮廓箱线图（展示四分位数和异常值）+ 均值点 + 成对统计检验显著性标注。

## 设计要点

1. 提琴图 (geom_violin) 使用 trim = FALSE 保留完整密度尾部，alpha = 0.28 半透明填充，避免遮挡。
2. 箱线图 (geom_boxplot) 居中叠加，宽度 0.22，突出四分位距；outlier.shape = NA 隐藏异常值点以简化视觉。
3. 均值点 (stat_summary) 用空心圆形（shape=23）标注每组的算术平均值。
4. 配色 采用 Tableau 10 的前三色调，蓝 / 橙 / 绿，区分三个物种组。
5. 显著性 通过 ggpubr::stat_compare_means 自动计算两两独立样本 t 检验并添加括号标注。

## 适用场景

- 小样本多组比较（如 3-6 个实验组）
- 需要同时展示分布形态与集中趋势
- 向期刊投稿时展示组间差异统计检验

## 注意事项

- 本模块使用 IRIS 内置数据集作为示例，用户替换为自身数据时只需修改 data 参数。
- t 检验假设数据近似正态分布；若方差不齐可改用 method = wilcox.test。
- preview.png 由脚本自动生成，sha256 需重新计算后填入 module.yml。
