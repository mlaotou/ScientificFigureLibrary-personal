# 详细描述

本模块展示了使用 ggtern 包绘制三元相图（ternary plot）的方法，用于可视化三个组分（A/B/C）的组成关系。

## 设计要点

1. **三元坐标系**：ggtern 包扩展 ggplot2，支持三元坐标（ternary coordinate）的映射。
2. **分组着色**：使用 RColorBrewer 的 Set1 调色板，为四个分组（T/D/L/K）分配区分度高的颜色。
3. **点大小编码**：通过 `aes(size = mean_value)` 将平均值映射为点大小，增强信息层次。
4. **背景渐变**：使用 PuOr 调色板创建半透明背景，提升视觉效果。
5. **主题定制**：采用 theme_classic() 基础，自定义坐标轴线样式和标题位置。

## 适用场景

- 微生物群落组成分析（如 OTU 在三个环境梯度下的分布）
- 地球化学样品分类（如岩石矿物三组分比例）
- 材料科学成分设计（如三元合金配比优化）
- 任何涉及三个百分比/比例变量的数据可视化

## 注意事项

- 代码中已内嵌示例数据，用户可直接运行查看效果
- 替换为自有数据时，需确保数据格式为三列百分比数据
- 分组数量可与示例不同，修改 `rep()` 函数中的向量即可
- preview.png 需与代码实际输出一致，sha256 校验用于验证完整性
