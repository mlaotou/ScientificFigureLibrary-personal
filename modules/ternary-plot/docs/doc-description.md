# 三元相图使用说明

## 图表类型
三元相图（Ternary Plot）

## 可视化目的
展示三个组分（A/B/C）的组成比例关系，适用于微生物组成、地质样品、材料配方等数据。

## 输入数据要求
- 三列数值数据，表示三个组分的百分比或相对丰度
- 可选的 ID 列用于标识样本
- 分组信息可通过代码中的 group 变量指定

## 参数调整
1. 修改 `data_text` 变量可替换示例数据
2. 修改 `df$group` 可更改分组标签
3. 修改配色方案需调整 `colorRampPalette` 的参数

## 输出文件
- preview.png：预览图
- thumbnail.jpg：缩略图
